# Icecream Problem — 逆向分析与自动化记录

对 [softserve.nog.cc](https://softserve.nog.cc/) 这款「挤冰淇淋堆高」小游戏的逆向分析记录：
从读懂它的物理判定开始，到用自动化程序把成绩从 **48cm 推到 213.7cm**。

> 个人娱乐用途的研究记录。仓库不包含游戏任何原始代码。

## 成绩

| 阶段 | 成绩 | 手段 |
|---|---|---|
| 人工基线 | 48 cm | 手动操作 |
| 参数调优 | 56.6 cm | 自动化 + 网格搜索 |
| 高速大圈 | 90.5 cm | 找到 `stroke` 隔离机制 |
| 常规路线极限 | **103.9 cm** | 同机制调到极值 |
| `dropBelow` 捷径 | **213.7 cm** | 绕过分层隔离 |

最终记录 **213.7 cm**，约为原始成绩的 4.4 倍。

## 游戏机制一句话版

高度只增不减；每次落点要么被限速地走（每帧 0.031 单位），要么被直接挂到塔顶（每层 +0.306 单位）；
塔在累计倾角达到 `toppleLean = 1.2` 时倒塌。所有策略本质上都在做两件事：**让每帧都走第二条分支**，以及**在倾角攒满之前收手**。

详细判定链见 [docs/mechanics.md](docs/mechanics.md)。

## 两条路线

### 1. 常规堆叠（稳定，硬顶 ~104cm）

落点每帧最多移动 `extrusionLengthPerSecond × dt × 2.5 = 0.031` 单位。
系统只把 `stroke` 差值 ≥ `neighboringStroke = 0.72` 的旧点当作支撑，所以要让一层「独立」，需要积累 0.72 的 stroke —— 即 **0.38 秒/层**。

高速大圈（快速旋转让 `stroke` 迅速累积）能把速度提到 5.4cm/s，但塔在约 19 秒后因倾角累积倒塌，两者相乘锁死在 104cm 附近。

```bash
# 稳定配置（成功率约 2/3）
python src/synth_model.py 0.51 0.28 -0.08 0 0.10 19.2 1.1 run1 999 0 0 0 0 0 0 1
```

### 2. `dropBelow` 捷径（快，混沌，130~215cm）

当目标点离塔的弯曲轴线超过 `creamDiameter/2 × missShift = 0.45` 时，游戏不再「慢慢堆」，而是直接找塔上能接住的最高点挂上去，并一次性把 `stroke` 推 0.72。把旋转周期压到 0.03 秒，每帧都满足该条件，于是绕过了 0.38 秒/层的隔离限制。

```bash
# 冲刺配置（约 22cm/s，但每次落在 130~215 的哪一段看运气）
python src/synth_model.py 0.51 0.03 -0.11 0 0.10 9.0 1.1 run1 999 0 0 0 0 0 0 1
```

**这条路线是混沌的。** 相位 `2πt/0.03` 对帧时刻极度敏感，不到 0.1ms 的抖动累积几十帧后完全去相关，同一组参数每次运行的轨迹都不同。

## 策略演进

| 阶段 | 做法 | 结果 |
|---|---|---|
| 直觉调参 | 匀速小圈、减慢转速 | 49.7 ~ 56.6 |
| 关键突破 | 高速大半径圆周（`stroke` 迅速累积，支撑退化成单点） | 90.5 |
| 极值搜索 | (R, p) 网格 + 质心补偿 + 时变参数 | 103.9 封顶 |
| 机制绕过 | 极端转速触发 `dropBelow` | 201.0 → 213.7 |
| 后续尝试 | 李萨如轨迹、倾角反馈、底座加固、阶跃切换 | 全部劣于 213.7 |

## 已排除的方向

以下都被实测否定，记录在此以免重复：

- **质心反向补偿**：只多 2cm，且引入振荡
- **李萨如轨迹**（扫圆盘提高挂载命中率）：塔寿命掉到 4~7 秒，最高 142
- **倾角反馈**（`alpha` ±2/5/10）：全部落在混沌分布的正常区间
- **底座加固**（先慢速夯底座再冲刺）：寿命延长到 12 秒，但前期损失过多，最高 173
- **阶跃切换**（稳定堆到 104 后切冲刺）：切换后 1 秒内必塌
- **piling / 静止堆叠**：增速仅约 1cm/s

共约 **120 组**配置。

## 复现说明

运行器通过 Playwright 驱动真实浏览器，向 `#operation-area` 合成 `PointerEvent`，并按圆周轨迹逐帧下发坐标。同时把从页面 bundle 中提取的物理类作为影子模型并行运行，用于实时读取高度、倾角、质心等状态。

**本仓库不包含游戏的原始代码或其提取物**（`sim_core.js`）。`sim_run.js` 与 `experiments/` 下的脚本依赖它才能离线运行；运行器 `synth_model.py` 则需要自行准备。

## 参数速查

| 参数 | 含义 |
|---|---|
| `R` | 轨迹半径（单位：内部单位，1 单位 = 5cm） |
| `p` | 旋转周期（秒） |
| `oz` | 轨迹圆心的 z 偏移 |
| `alpha` | 倾角反馈增益 |
| `maxShift` | 反馈最大偏移 |
| `stopT` | 固定停手时刻（秒） |
| `stopCm` | 达到该高度即停手 |
| `beta` | 倾角变化率阻尼 |
| `ccGain` | 质心回中增益 |
| `p2` / `pT` | 时变周期目标值 / 过渡时刻（负值启用阶跃） |
| `liss` | z 轴频率比（≠1 时为李萨如轨迹） |
