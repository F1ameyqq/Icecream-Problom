## 四、`dropBelow` 捷径的发现

离线扫描显示：极高转速下模型高度暴涨。追踪曲线（`sim33`）确认高度是**线性稳定增长**（每 0.5 秒 +15.1cm），`stroke` 每帧 +0.75 ≈ `neighboringStroke`，即每帧都在走 `dropBelow` 分支。

| 批次 | 配置 | 结果 |
|---|---|---|
| `z1` | R=0.51 p=0.03 stopT=9.0 | **201.0 —— 完成** |
| `z2` | stopT=15 / 20 / 25 | 192.3 倒 / 230.1 倒 / 169.8 倒 |
| `z3` | stopT=9.4 / 9.6 / 9.8 | 195.2 倒 / 155.5 倒 / 151.7 完成 |
| `z4` | R=0.65×2 / R=0.40 | 111.4 / 120.3 完成 / 135.3 倒 |
| `z5` | R=0.48 / 0.54 / 0.57 | 152.7 倒 / 136.8 完成 / 141.8 完成 |
| `z5` | p=0.025 / p=0.035 | 128.4 倒 / 58.5 倒（**0.035 已无法触发**） |
| `z5` | **oz=-0.11** | **213.7 —— 完成** |

**关键发现**：`p=0.035` 时代码路径完全变了（5 秒停滞），说明触发窗口极窄（`p < 约 0.032`）。而停手时刻与高度**没有单调关系**——9.0s→201、9.4s→195(倒)、9.6s→155(倒)、9.8s→152。

## 八、统计

- 页面实际运行：**约 110 局**
- 离线配置探索：**约 120 组**
- 最终记录：**213.7cm**

## 九、结论

1. **常规堆叠**受「每帧 0.031 位移限速 + 0.72 stroke 隔离」双重约束，理论增速上限 7.4cm/s，实际稳定窗口约 19 秒 → **104cm 硬顶**
2. **`dropBelow` 捷径**绕过 stroke 隔离，增速 22cm/s，但塔寿命仅约 10 秒 → **量级上限约 220cm**
3. 这条路径是**混沌的**，同一参数产出在 130~215 之间随机分布
4. 所有「让塔更稳」的尝试（底座加固、李萨如、倾角反馈、阶跃切换）都缩短了寿命，净效果为负
5. **瓶颈是塔的结构寿命，不是摞层速度**——而这无法通过控制输入来解决
